# Хронометр: как запустить свой сайт

В папке всё приложение: `index.html`, `app.js`, шрифты в папке `fonts`, иконки, `manifest.webmanifest` и `sw.js` (чтобы его можно было поставить на телефон и открывать без интернета). Записи хранятся в браузере того устройства, где вы работаете.

## 1. Разместить на GitHub Pages (бесплатно, ~10 минут)

1. Зарегистрируйтесь на [github.com](https://github.com), если аккаунта ещё нет.
2. Нажмите **New repository**. Название, например, `hronometr`, видимость **Public**, остальное не трогайте. **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите все файлы из этой папки (не саму папку, а её содержимое). Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В «Branch» выберите `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сверху появится адрес вида `https://ваш-логин.github.io/hronometr/`. Это ваше приложение.

Чтобы обновить приложение, загрузите новый `index.html` тем же способом. Он подтянется у вас при следующем открытии.

## 2. Поставить на телефон

- **iPhone:** откройте адрес в Safari → кнопка «Поделиться» → «На экран „Домой“».
- **Android:** откройте в Chrome → меню ⋮ → «Установить приложение».

На iPhone записи из Safari и из установленного значка хранятся отдельно, поэтому пользуйтесь чем-то одним. Лучше значком: Safari может удалить данные сайта, который не открывали больше недели, а установленное приложение это не затрагивает.

## Справочник

- **Активности по проектам.** У каждого проекта под названием есть строка «активности: все» → «выбрать». Отметьте активности этого проекта, и при запуске таймера после выбора проекта в списке останутся только они. Если ничего не отмечено, показываются все.
- **Загрузить списком.** В карточке «Категории активностей» есть кнопка «Загрузить списком». Вставьте столбец из Excel или Google Таблицы либо выберите файл .txt или .csv: по одной активности в строке. Во втором столбце можно указать проекты, несколько через запятую. Тогда активность сразу привяжется к ним, а недостающие проекты создадутся. Перед добавлением видно, что именно появится. Файл Excel (.xlsx) сначала сохраните как CSV.

Пример для вставки (столбцы разделены табуляцией, как при копировании из таблицы, или «;»):

```
Созвон
Анализ отчётности; Клиент «Вектор»
Подготовка выступления; Выступления, Личный бренд
```

## 3. Подключить Google Таблицу

Хронометр сам отправляет записи в вашу Google Таблицу через небольшой скрипт внутри неё. Google Cloud, ключи разработчика и повторный вход не нужны. Настраивается один раз, примерно за 5 минут:

1. Создайте Google Таблицу или откройте свою рабочую, куда нужны записи. Меню **«Расширения» → «Apps Script»**.
2. В Хронометре нажмите значок базы данных справа вверху → **«Скопировать код скрипта»**. В редакторе Apps Script удалите всё, вставьте код и сохраните (значок дискеты).
3. В Apps Script: **«Начать развёртывание» → «Новое развёртывание»** → шестерёнка → **«Веб-приложение»**.
   - «Запуск от имени»: **Я**
   - «У кого есть доступ»: **Все**

   Нажмите «Начать развёртывание». Google попросит разрешить скрипту доступ к таблице. Если он предупредит, что «приложение не проверено», это ваш собственный скрипт: «Дополнительно» → «Перейти».
4. Скопируйте **URL веб-приложения** (заканчивается на `/exec`), вставьте в Хронометр в поле «адрес скрипта» и нажмите **«Подключить и отправить»**.

В таблице появится лист **«Записи»**: дата, начало, окончание, минуты, часы, категория, проект, комментарий.

### Как это работает дальше

- Через несколько секунд после каждой остановки таймера, правки или удаления записи таблица обновляется сама. Ничего нажимать не нужно.
- Лист «Записи» каждый раз перезаписывается целиком, поэтому руками на нём ничего не меняйте. Свои расчёты делайте на других листах той же таблицы со ссылками на «Записи», например `=СУММЕСЛИ('Записи'!G:G; "Клиент «Вектор»"; 'Записи'!E:E)` — часы по проекту.
- Синхронизация идёт в одну сторону: из Хронометра в таблицу.
- Если интернета не было, таблица обновится при следующем изменении или по кнопке «Отправить сейчас».

### Почему «Доступ: Все» безопасно

Без этого Хронометр не сможет достучаться до скрипта. Но записать что-то в таблицу можно только с ключом. Ключ вшит в код скрипта и хранится в вашем браузере. Прочитать данные через скрипт нельзя никому: по его адресу открывается только строка «Хронометр». Саму таблицу по-прежнему видите только вы.

### Если перенесли Хронометр на другой адрес или устройство

У нового браузера будет свой ключ. Откройте значок базы данных → «Как подключить (если нужно заново)» → «Скопировать код скрипта». Замените код в Apps Script и сделайте **«Управление развёртываниями» → карандаш → «Новая версия» → «Развернуть»**. Адрес скрипта при этом не меняется.

## Где хранятся данные

- Только в браузере устройства, где вы работаете. На другие устройства сами не переносятся.
- Время от времени нажимайте **Скачать копию** в окне «Данные и выгрузка». Файл копии можно открыть на другом устройстве через **Восстановить из копии…**.
- Если очистить данные сайтов в браузере, записи пропадут. Восстановить их можно из копии или вручную из Google Таблицы.

## Безопасность

Что защищено:

- **Записи никуда не уходят, кроме вашей таблицы.** Они лежат в браузере устройства. Единственное место, куда приложение их отправляет, — скрипт в вашей Google Таблице, и только если вы его подключили. Шрифты тоже лежат в самом приложении.
- **Чужой код не запустится.** Названия, комментарии и файлы резервных копий проверяются, текст всегда выводится как текст. Политика безопасности браузера (CSP) запрещает загружать скрипты откуда-либо, кроме самого приложения, и отправлять данные куда-либо, кроме Google Apps Script.
- **Поддельная резервная копия не навредит.** При восстановлении берутся только известные поля проверенного типа. Адрес и ключ Google-скрипта из файла не берутся никогда.
- **Выгрузки безопасны для Excel и Google Таблиц.** Текст, который начинается с `=`, `+`, `-` или `@`, не превратится в формулу.
- **Приложение нельзя встроить в чужой сайт**, чтобы обманом заставить вас нажимать кнопки.
- **Скрипт в таблице только записывает.** Без ключа он ничего не примет, а данных не отдаёт никому.

Что зависит от вас:

1. **Отдельный адрес для Хронометра.** Все сайты на `ваш-логин.github.io` для браузера — один и тот же сайт, и они могут читать данные друг друга. Если держите на GitHub Pages ещё что-то, особенно чужой код, подключите Хронометру свой адрес, например `time.memofinance.ru`: Settings → Pages → Custom domain. Это бесплатно, нужна только запись в настройках домена. Или заведите для Хронометра отдельный аккаунт GitHub.
2. **Блокировка устройства.** Любой, кто откроет ваш браузер, увидит записи. Держите на телефоне и компьютере пароль или Face ID.
3. **Резервные копии и CSV не зашифрованы.** Храните их там же, где другие рабочие документы, и не пересылайте в открытые чаты.
4. **Двухфакторная защита в Google.** Таблица с записями защищена вашим аккаунтом Google, поэтому включите на нём двухэтапную проверку. Не открывайте доступ к таблице «всем, у кого есть ссылка».
5. **Не включайте приватный режим** для работы с Хронометром: в нём браузер стирает записи при закрытии.
