# Хронометр: как запустить свой сайт

В папке всё приложение: `index.html`, `app.js`, шрифты в папке `fonts`, иконки, `manifest.webmanifest` и `sw.js` (чтобы его можно было поставить на телефон и открывать без интернета). Записи хранятся в браузере того устройства, где вы работаете.

## 1. Разместить на GitHub Pages (бесплатно, ~10 минут)

1. Зарегистрируйтесь на [github.com](https://github.com), если аккаунта ещё нет.
2. Нажмите **New repository**. Название, например, `hronometr`, видимость **Public**, остальное не трогайте. **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите все файлы из этой папки (не саму папку, а её содержимое). Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В «Branch» выберите `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сверху появится адрес вида `https://ваш-логин.github.io/hronometr/`. Это ваше приложение.

Чтобы обновить приложение, загрузите новый `index.html` тем же способом. Он подтянется у вас при следующем открытии.

## 2. Поставить на телефон

- **iPhone:** откройте адрес в Safari → кнопка «Поделиться» → «На экран „Домой“».
- **Android:** откройте в Chrome → меню ⋮ → «Установить приложение».

На iPhone записи из Safari и из установленного значка хранятся отдельно, поэтому пользуйтесь чем-то одним. Лучше значком: Safari может удалить данные сайта, который не открывали больше недели, а установленное приложение это не затрагивает.

## 3. Подключить выгрузку в Google Таблицу

Это делается один раз, нужен ключ доступа (Client ID) из Google Cloud.

1. Откройте [console.cloud.google.com](https://console.cloud.google.com) и создайте проект, например «Хронометр».
2. **APIs & Services → Library** → найдите **Google Sheets API** → **Enable**.
3. **Google Auth Platform → Branding:** заполните название приложения и свой e-mail. В **Audience** выберите **External** и добавьте свой e-mail в **Test users**.
4. **Clients → Create client** → тип **Web application**. В **Authorized JavaScript origins** добавьте адрес сайта без пути, например `https://ваш-логин.github.io`.
5. Скопируйте **Client ID** (заканчивается на `.apps.googleusercontent.com`).
6. В Хронометре нажмите значок базы данных справа вверху, вставьте Client ID и нажмите **Выгрузить в Google Таблицу**.

Google один раз спросит разрешение. Приложение получает доступ только к файлам, которые создало само, остальной Google Диск ему не виден. Пока приложение в режиме тестирования, Google может предупредить, что оно не проверено: это нормально, нажмите «Продолжить».

На Диске появится таблица **«Хронометр»** с листом **«Записи»**: дата, начало, окончание, минуты, часы, категория, проект, комментарий.

### Как обновляется таблица

- Лист «Записи» всегда показывает **все** записи из Хронометра. При каждом обновлении он перезаписывается целиком, поэтому руками на нём ничего не меняйте: правки сотрутся.
- После нажатия **«Обновить таблицу»** около часа таблица обновляется сама, через несколько секунд после каждой остановки таймера, правки или удаления записи. Потом Google просит войти снова, и это ограничение браузера: без вашего нажатия окно входа открыть нельзя. Достаточно нажать «Обновить таблицу» ещё раз, например в начале рабочего дня.
- Синхронизация идёт в одну сторону: из Хронометра в таблицу. Изменения в таблице в Хронометр не попадают.

### Как подключить записи к своей рабочей таблице

Если у вас уже есть таблица с расчётами (себестоимость часа, загрузка по клиентам и т. п.), не переносите туда данные вручную. Подтяните их формулой:

1. Откройте таблицу «Хронометр» и скопируйте её адрес из строки браузера.
2. В своей таблице на отдельном листе, например «Время», в ячейку A1 вставьте:
   ```
   =IMPORTRANGE("адрес таблицы Хронометр"; "Записи!A:H")
   ```
3. Google один раз попросит «Открыть доступ». Нажмите, и данные появятся.

Дальше этот лист обновляется сам вслед за «Хронометром». Сводные таблицы и формулы стройте на нём, например: `=СУММЕСЛИ('Время'!G:G; "Клиент «Вектор»"; 'Время'!E:E)` — часы по проекту.

## Где хранятся данные

- Только в браузере устройства, где вы работаете. На другие устройства сами не переносятся.
- Время от времени нажимайте **Скачать копию** в окне «Данные и выгрузка». Файл копии можно открыть на другом устройстве через **Восстановить из копии…**.
- Если очистить данные сайтов в браузере, записи пропадут. Восстановить их можно из копии или вручную из Google Таблицы.

## Безопасность

Что защищено:

- **Записи никуда не отправляются** сами. Они лежат только в браузере устройства. Приложение не обращается ни к каким сайтам, кроме Google, и только когда вы сами выгружаете таблицу. Шрифты тоже лежат в самом приложении.
- **Чужой код не запустится.** Названия, комментарии и файлы резервных копий проверяются, текст всегда выводится как текст. Политика безопасности браузера (CSP) запрещает загружать скрипты откуда-либо, кроме самого приложения и входа Google.
- **Поддельная резервная копия не навредит.** При восстановлении берутся только известные поля проверенного типа. Настройки Google из файла не берутся никогда.
- **Выгрузки безопасны для Excel и Google Таблиц.** Текст, который начинается с `=`, `+`, `-` или `@`, не превратится в формулу.
- **Приложение нельзя встроить в чужой сайт**, чтобы обманом заставить вас нажимать кнопки.
- **Доступ к Google минимальный:** приложение видит только таблицы, которые создало само. Ключ доступа хранится только в памяти вкладки и пропадает при её закрытии.

Что зависит от вас:

1. **Отдельный адрес для Хронометра.** Все сайты на `ваш-логин.github.io` для браузера — один и тот же сайт, и они могут читать данные друг друга. Если держите на GitHub Pages ещё что-то, особенно чужой код, подключите Хронометру свой адрес, например `time.memofinance.ru`: Settings → Pages → Custom domain. Это бесплатно, нужна только запись в настройках домена. Или заведите для Хронометра отдельный аккаунт GitHub.
2. **Блокировка устройства.** Любой, кто откроет ваш браузер, увидит записи. Держите на телефоне и компьютере пароль или Face ID.
3. **Резервные копии и CSV не зашифрованы.** Храните их там же, где другие рабочие документы, и не пересылайте в открытые чаты.
4. **Двухфакторная защита в Google.** Таблица «Хронометр» защищена вашим аккаунтом Google, поэтому включите на нём двухэтапную проверку. Не открывайте доступ к таблице «всем, у кого есть ссылка».
5. **Не включайте приватный режим** для работы с Хронометром: в нём браузер стирает записи при закрытии.
